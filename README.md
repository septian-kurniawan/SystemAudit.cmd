# SystemAudit.cmd
Audit otomatis mendeteksi spesifikasi inti PC secara aman dan bebas error. Mampu memeriksa produsen perangkat, OS, CPU, total RAM, hingga kapasitas serta sisa ruang partisi disk. Seluruh hasil pemindaian direkap secara rapi ke dalam file teks laporan sistem dengan format waktu terkini.
